# Image To PDF

> 免费 · 纯前端 · 永久在线

所有图片均在浏览器本地处理，不上传任何服务器，保护您的隐私。

## 快速开始

```bash
npm install
npm run dev
```

## 技术栈
React 18 + Vite 6 + TypeScript + Tailwind CSS 3 + pdf-lib

## 部署到 GitHub Pages

1. 创建 GitHub 仓库 image-to-pdf
2. git push 到 main 分支
3. Settings -> Pages -> Source 选择 GitHub Actions
4. 访问 https://<用户名>.github.io/image-to-pdf/
